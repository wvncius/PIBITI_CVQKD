# Glossário — Projeto PIBITI CV-QKD

## 1. QKD — Distribuição Quântica de Chaves

Método para estabelecer chaves criptográficas utilizando princípios da mecânica quântica.

## 2. CV-QKD — Distribuição Quântica de Chaves por Variáveis Contínuas

Modalidade de QKD que utiliza variáveis contínuas, como quadraturas do campo eletromagnético, para representar informações.

## 3. Reconciliação de informação

Etapa do pós-processamento clássico em que Alice e Bob procuram corrigir diferenças entre seus dados correlacionados.

## 4. Mapeamento antipodal

Conversão de bits em símbolos com sinais opostos, segundo uma convenção definida:

- Bit 0 → +1
- Bit 1 → −1

## 5. Canal BI-AWGN

Modelo de canal com entrada binária e ruído gaussiano branco aditivo.

Sua equação é:

Y = X + Z

Onde X representa o símbolo transmitido, Z representa o ruído gaussiano e Y representa o sinal recebido.

## 6. BER — Bit Error Rate

Taxa de erro de bits, calculada dividindo o número de bits incorretos pelo total de bits transmitidos.
