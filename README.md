# Módulos de Software para Simulador CV-QKD (Reconciliação de Informação)

## 📌 Descrição do Projeto
Este repositório contém o desenvolvimento dos módulos de software destinados à simulação de rotinas de reconciliação de informação em sistemas de Distribuição Quântica de Chaves com Variáveis Contínuas (CV-QKD).

Proposta desenvolvida no âmbito do projeto de pesquisa/iniciação científica (PIBITI).

---

## 📁 Estrutura do Repositório
* `src/`: Código-fonte dos módulos do simulador.
* `tests/`: Scripts de teste e verificação dos algoritmos.
* `docs/`: Relatórios acadêmicos, referências teóricas e notas de projeto.
* `data/`: Entradas e saídas de simulação de exemplo.

---

## 🚀 Como Executar

### Pré-requisitos
* Python 3.10+ (ou compilador C++)
* Dependências listadas em `requirements.txt`

### Instalação e Execução
```bash
# Clone o repositório
git clone [https://github.com/SEU-USUARIO/PIBITI_QVCKD.git](https://github.com/SEU-USUARIO/PIBITI_QVCKD.git)

# Acesse o diretório
cd PIBITI_QVCKD

# Instale as dependências (se em Python)
pip install -r requirements.txt

# Execute o script principal
python src/main.py
